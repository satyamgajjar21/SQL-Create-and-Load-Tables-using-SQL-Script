# 🩺 Cardio-Vascular Diseases (CVD) Database Lab using MySQL & phpMyAdmin

Welcome to the **CVD Database Hands-on Lab**! This project walks you through creating and managing a relational database using **MySQL** with the **phpMyAdmin GUI**. You'll build a fully functional medical database centered on cardio-vascular disease data.

---

## 🚀 Lab Objectives

By completing this lab, you will:

✅ Create a new MySQL database using phpMyAdmin  
✅ Create tables using a pre-written SQL script  
✅ Load data into the tables from CSV files  
✅ Browse and verify the data in each table

---

## 🛠️ Technologies Used

- **MySQL** – Relational Database Management System (RDBMS)  
- **phpMyAdmin** – Web-based MySQL database administration tool  
- **CSV Files** – Used for data import  
- **SQL Scripts** – Used for table creation
